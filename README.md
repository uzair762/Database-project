📝 Project Description

This project helps manage crime-related data such as cases, criminals, and case status. Users can add new records, update existing ones, and search for specific cases. The system improves accuracy, security, and efficiency in handling crime records.

🛠️ Technologies Used

Programming Language: Java

Database: MySQL

GUI: Java Swing

IDE: NetBeans / IntelliJ

✨ Features

Add new crime records

Update and delete records

Search crime cases

View case status

Secure data handling

🚀 How to Run

Import the project into your Java IDE

Set up the database using provided SQL file

Configure database connection

Run the main Java file
